# 🎂 Irina's 18th Birthday

A personalized, interactive web application built as an 18th birthday gift and web development showcase. Features a multi-page scrapbook design, integrated Spotify player, dynamic gallery, and interactive wishes board.


---

## ✨ Features

* *Landing Card:* Custom welcome hero screen with active navigation and dynamic styling.
* *Photo Memories Gallery:* Responsive photo grid showcasing core memories.
* *Mixtape Page:* Seamlessly embedded Spotify music player with custom vinyl aesthetic styling.
* *Virtual Wishes Board:* Scrapbook-style sticky note wall with rotated message cards and hover effects.
* *Unified Navigation:* Consistent top navigation bar with dynamic .active page highlighting.

---

## Built With

* *HTML5:* Semantic layout and multi-page structure.
* *CSS3:* Custom styling featuring Flexbox, CSS transforms, absolute positioning, and dynamic hover states.
* *Integrations:* Spotify Web iFrame API.
* *Hosting:* GitHub Pages.

---

## What I Learned & Challenges Overcome

Building this site helped me strengthen key frontend development skills:

1. *Relative vs. Absolute Positioning:* Solved navigation bar positioning issues by fixing overlapping elements on centered flex headers.
2. *Standardizing iFrame Embeds:* Fixed duplicate <iframe> syntax errors when embedding the Spotify media player to ensure responsive media rendering across screens.
3. *Responsive Image Styling:* Utilized object-fit: cover and border-radius: 50% to properly crop rectangular images into perfect circular profiles without aspect ratio distortion.
